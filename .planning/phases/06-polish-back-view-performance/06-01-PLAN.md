<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Keyboard event -> selection state | Untrusted key events can mutate selection state and focus order. |
| Selection state -> live region | Internal interaction state becomes screen-reader-visible text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | keyboard navigation model | mitigate | Accept only Arrow/Enter/Space for keyboard selection changes and keep focus order derived from current visible IDs. |
| T-06-02 | Denial of Service | aria-live announcer | mitigate | Announce only user-facing selection changes and avoid repeated spam during bulk resets or internal state sync. |
</threat_model>
