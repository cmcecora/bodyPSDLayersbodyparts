<objective>
Implement the "Dual Data Mode" for &lt;body-map-explorer&gt;. This allows the component to operate as a standalone unit with bundled data (Standalone Mode) or as an integrated component that consumes data from a host application (Integrated Mode). By abstracting data access through a DataProvider interface, we enable flexible integration patterns including static JSON injection or custom API clients.

Purpose: Enable full integration with external host applications (like the medical directory site).
Output: Refactored data layer, updated explorer component with Dual Data Mode logic, comprehensive test suite, and a demo in the standalone testbed.
</objective>
