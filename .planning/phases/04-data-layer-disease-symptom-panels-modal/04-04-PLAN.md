    **Positioning logic (per D-10, RESEARCH Pattern 4):**
    ```typescript
    private _computePosition() {
      const modalW = 520;
      const modalH = 440;
      const gap = 12;
      const caratSize = 14;
      const vw = window.innerWidth;
      const vh = window.innerHeight;

      let left = this.anchorX + gap;
      let top = this.anchorY - modalH / 2;

      // Flip left if no room on right
      if (left + modalW > vw - 16) {
        left = this.anchorX - modalW - gap;
      }
      // Clamp vertical
      top = Math.max(16, Math.min(top, vh - modalH - 16));

      this._modalStyle = `left:${left}px;top:${top}px`;

      // Carat points at click location
      const caratLeft = left > this.anchorX
        ? left - caratSize / 2   // modal is to the right, carat on left edge
        : left + modalW - caratSize / 2;  // modal is to the left, carat on right edge
      const caratTop = this.anchorY - caratSize / 2;
      this._caratStyle = `left:${caratLeft}px;top:${caratTop}px`;
    }
    ```

       ```typescript
       private async _handleSectionClick(event: CustomEvent<{
         sectionId: string; sectionName: string; clientX: number; clientY: number;
       }>) {
         const { sectionId, sectionName, clientX, clientY } = event.detail;

         // Toggle: clicking the same section closes the modal
         if (this._modalSectionId === sectionId) {
           this._closeModal();
           return;
         }

         this._modalSectionId = sectionId;
         this._modalSectionName = sectionName;
         this._modalAnchorX = clientX;
         this._modalAnchorY = clientY;
         this._modalDiseases = [];
         this._modalSymptoms = [];
         this._modalError = null;
         this._modalLoading = true;

         // Look up body part keys for this section
         const bpKeys = SECTION_TO_BP_KEYS[sectionId] ?? [];

         try {
           // Fetch diseases and symptoms for all body parts in this section
           const [diseasesArrays, symptomsArrays] = await Promise.all([
             Promise.all(bpKeys.map(key => fetchDiseases(key).catch(() => []))),
             Promise.all(bpKeys.map(key => fetchSymptomsForPart(key).catch(() => []))),
           ]);

           // Flatten and deduplicate
           const allDiseases = diseasesArrays.flat();
           const uniqueDiseases = Array.from(
             new Map(allDiseases.map(d => [d.name, d])).values()
           );

           const allSymptoms = symptomsArrays.flat();
           const uniqueSymptoms = Array.from(new Set(allSymptoms));

           this._modalDiseases = uniqueDiseases;
           this._modalSymptoms = uniqueSymptoms.sort();
         } catch (err) {
           this._modalError = String(err);
         } finally {
           this._modalLoading = false;
         }
       }
       ```

## Trust Boundaries

| Boundary                                     | Description                                               |
| -------------------------------------------- | --------------------------------------------------------- |
| Section click coordinates -> modal position  | User-initiated click coordinates used for CSS positioning |
| Aggregated disease/symptom data -> modal DOM | Data from multiple body part files rendered in modal      |
| Escape key / backdrop click -> modal state   | User interaction triggers state cleanup                   |

## STRIDE Threat Register

| Threat ID | Category               | Component                  | Disposition | Mitigation Plan                                                                                                                                                         |
| --------- | ---------------------- | -------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-04-08   | Tampering              | Modal content rendering    | mitigate    | All disease names and symptom strings rendered via Lit `html` template literal auto-escaping. Checkbox labels use `${symptomName}` text interpolation, never innerHTML. |
| T-04-09   | Tampering              | Modal search input         | mitigate    | Search query used only in `.toLowerCase().includes()` comparison. Never reflected into DOM outside Lit auto-escaped binding. No regex construction.                     |
| T-04-10   | Spoofing               | Modal position coordinates | accept      | Coordinates come from MouseEvent.clientX/clientY which are already user-controlled (where they click). Used only for CSS `left`/`top` positioning. No security impact.  |
| T-04-11   | Information Disclosure | Aggregated section data    | accept      | All disease/symptom data is public health information. No user-specific or private data exposed. Section aggregation just combines public data files.                   |
