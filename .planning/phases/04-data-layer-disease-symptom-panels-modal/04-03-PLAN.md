       ```typescript
       private async _loadOrganData(organId: string) {
         if (this._diseasesMap.has(organId) || this._loadingIds.has(organId)) return;

         this._loadingIds = new Set([...this._loadingIds, organId]);

         try {
           const [diseases, symptoms] = await Promise.all([
             fetchDiseases(organId),
             fetchSymptomsForPart(organId),
           ]);

           const nextDiseases = new Map(this._diseasesMap);
           nextDiseases.set(organId, diseases);
           this._diseasesMap = nextDiseases;

           const nextSymptoms = new Map(this._symptomsMap);
           nextSymptoms.set(organId, symptoms);
           this._symptomsMap = nextSymptoms;
         } catch (err) {
           const nextErr = new Map(this._errorIds);
           nextErr.set(organId, String(err));
           this._errorIds = nextErr;
         } finally {
           const next = new Set(this._loadingIds);
           next.delete(organId);
           this._loadingIds = next;
         }
       }
       ```

## Trust Boundaries

| Boundary                              | Description                                                           |
| ------------------------------------- | --------------------------------------------------------------------- |
| DataService response -> DOM rendering | Disease names and symptom strings from JSON rendered in Lit templates |
| User search input -> filter function  | Text from search input used in string .includes() comparison          |

## STRIDE Threat Register

| Threat ID | Category          | Component                                             | Disposition | Mitigation Plan                                                                                                                                                                                  |
| --------- | ----------------- | ----------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| T-04-05   | Tampering         | Disease/symptom names in data panel                   | mitigate    | All data rendered via Lit `html` template literal string interpolation (`${disease.name}`), which auto-escapes HTML entities. No innerHTML or unsafeHTML used.                                   |
| T-04-06   | Tampering         | Search filter input                                   | mitigate    | Filter uses `.toLowerCase().includes(query)` on existing cached strings only. Input value is never inserted into DOM except via Lit auto-escaped binding. No regex construction from user input. |
| T-04-07   | Denial of Service | Rendering large disease lists (bp_arms: 6300 entries) | accept      | Lists are scrollable with overflow-y auto. Browser handles large DOM lists. If performance becomes an issue, a "show first 50" cap can be added in Phase 6 polish. Not a security concern.       |

</threat_model>
