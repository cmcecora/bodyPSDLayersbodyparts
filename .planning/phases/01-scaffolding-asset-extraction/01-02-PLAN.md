    This task has three sub-steps: extract base64 from HTML, convert existing PNGs, and verify all outputs.

    **Step 1: Create directory structure**
    ```bash
    mkdir -p public/assets/organs public/assets/body-parts public/assets/systems scripts
    ```

    **Step 2: Create scripts/extract-base64.ts**
    A Node.js script (can be run with `npx tsx`) that:
    1. Reads `interactive-body-model.html`
    2. Finds all `<g class="body-part-group"` elements, extracts `data-part` attribute value and the `href="data:image/png;base64,..."` from the child `<image>` element
    3. For each match: decode the base64 string, write to `public/assets/organs/{data-part}.png`
    4. Also finds BODY_SYSTEMS array entries, extracts each `thumbnail: "data:image/png;base64,..."`, writes to `public/assets/systems/{system_id}.png`
    5. Use regex parsing (not a full HTML parser) since the file structure is predictable:
       - Organ pattern: `<g[^>]*class="body-part-group"[^>]*data-part="([^"]+)"[^>]*>[\s\S]*?href="data:image/png;base64,([^"]+)"`
       - System pattern: `id:\s*"([^"]+)"[\s\S]*?thumbnail:\s*"data:image/png;base64,([^"]+)"`
    6. Print a count of extracted files for each category

    **Step 3: Create scripts/convert-to-webp.sh**
    A shell script that:
    1. Checks for `cwebp` command (from libwebp). If not found, install via `brew install webp` on macOS
    2. Converts all extracted organ PNGs in `public/assets/organs/` to WebP using: `cwebp -q 90 input.png -o output.webp`
    3. Converts all 77 body-part thumbnails from `bpart_images/*.png` to WebP in `public/assets/body-parts/`: `cwebp -q 90 bpart_images/filename.png -o public/assets/body-parts/filename.webp`
    4. Converts all 12 system images from `bodyimage/*.png` to WebP in `public/assets/systems/`: `cwebp -q 90 bodyimage/filename.png -o public/assets/systems/filename.webp`
    5. After WebP conversion, removes the intermediate organ PNGs from `public/assets/organs/` (the PNGs were only a stepping stone)
    6. Prints count of WebP files in each directory

    Quality setting: `-q 90` preserves medical illustration fidelity per research gap noted in SUMMARY.md. This can be tuned down later if file sizes are too large, but starting high ensures no visible quality loss.

    **Step 4: Run both scripts**
    ```bash
    npx tsx scripts/extract-base64.ts
    bash scripts/convert-to-webp.sh
    ```

    **Step 5: Verify counts**
    Expected outputs:
    - `public/assets/organs/`: At least 19 WebP files (one per SVG body-part-group with base64 image; some organs share layers so actual count may differ from the 66 base64 references — the 66 count includes BODY_SYSTEMS thumbnails and duplicates. The organ SVG groups contain ~19 unique images per grep of `class="part-image"`)
    - `public/assets/body-parts/`: 77 WebP files (one per PNG in `bpart_images/`)
    - `public/assets/systems/`: 12 WebP files (one per PNG in `bodyimage/`)

    Note: The "66 base64 strings" count from the HTML file includes both SVG organ images AND BODY_SYSTEMS JS thumbnails AND possible duplicates. The actual unique organ layer count is ~19 (matching `class="part-image"` count). The extraction script should deduplicate by `data-part` ID.
