**Gap 1 fix -- hit-area path transform (UAT tests 3, 4, 5):**

In `src/body-map-model.ts`, in the `_renderOrganGroup()` method (around line 390), change:

```typescript
<path class="hit-area" d=${organ.hitAreaPath} />
```

to:

```typescript
<path class="hit-area" d=${organ.hitAreaPath} transform=${`translate(${organ.imageX},${organ.imageY})`} />
```

This matches the original HTML pattern where every `<path class="hit-area">` has `transform="translate(imageX,imageY)"`. The path data in `src/data/organs.ts` uses organ-local coordinates starting near (0,0), so the translate positions the hit-area polygon over the correct organ image in the SVG viewport.
