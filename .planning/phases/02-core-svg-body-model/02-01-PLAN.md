**Step 3 — Extract body silhouette image:**

Create `scripts/extract-silhouette.mjs` — a Node.js ES module script that:

1. Reads `interactive-body-model.html` as a UTF-8 string.
2. Finds the `id="base-body"` image element (line ~1376).
3. Locates the `href="data:image/png;base64,` marker after that position.
4. Reads the base64 string character-by-character until the closing `"` (same pattern used by `scripts/extract-base64.mjs` from Phase 1).
5. Decodes the base64 to a Buffer and writes it as a PNG to a temp file.
6. Converts to WebP using `cwebp -q 90 temp.png -o public/assets/silhouette.webp`.
7. Deletes the temp PNG.
8. Logs `"Extracted silhouette to public/assets/silhouette.webp"`.

Run the script:

```bash
node scripts/extract-silhouette.mjs
```

If `cwebp` is not available, fall back to writing the PNG directly as `public/assets/silhouette.png` and note in the summary that WebP conversion was skipped (the component can reference either format).

Verify `public/assets/silhouette.webp` (or `.png`) exists and is non-empty (should be ~50-200 KB for a 698x1698 mostly-transparent silhouette).
